Set Theory · Gödel's First Incompleteness Theorem (Optional)

Lesson 1

Nikolai Chukhin · Alexander S. Kulikov

In this optional lesson, we show how one can derive Gödel's First Incompleteness Theorem from the undecidability of the Halting problem. This will be a hand-wavy proof: we will avoid providing some formal definitions; instead, we will try to outline the main idea of the proof. This lesson is based on a blog post by Noah Stephens-Davidowitz and a video by Veritasium.
