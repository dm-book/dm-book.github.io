Problem. Let \(H\) be a connected graph with a \(5\)-periodic coloring using three colors. Which statement must be true?

Question, Advanced problem
This problem can only be submitted at Cogniterra.

    \(e(H)<5v(H)\).

  2. 2

    \(e(H)\ge 5v(H)\).

  3. 3

    \(H\) contains an odd cycle.

  4. 4

    \(H\) has a vertex whose deletion disconnects the graph.
