Boolean Circuits · NAND Game: Memory (Optional)

Lesson 1

Nikolai Chukhin · Alexander S. Kulikov

The circuits constructed thus far possess no memory; however, memory is essential for the construction of non-trivial computing systems. Your task in this stage is to design a latch, a component capable of storing (“latching onto”) a single bit. This represents the simplest form of memory; nevertheless, by building upon this concept, one can construct larger and more sophisticated memory units.
