Problem. Which of the following formulas is satisfied by the model \(L\)?

Multiple choice, Advanced problem
This problem can only be submitted at Cogniterra.

    \(\forall x \ \exists y (x = y + y)\)

  2. 2

    \(\forall x (x \times 0 = 0)\)

  3. 3

    \(\forall x \ \forall y \ (x \times y = y \times x)\)

  4. 4

    \(\forall x \ \exists y \ (x \times y = x)\)

  5. 5

  6. 6

    \(\forall x , \forall y \ \forall z \ (x + z = y + z \Rightarrow x = y)\)
