Nikolai Chukhin · Alexander S. Kulikov

Programming problem. You are given the first row of a Greco-Latin square. Fill in the remaining cells.

  • Input format.  The first line contains an integer \(n=7\). Each of the following \(n\) lines contains a pair of numbers from the first row.
  • Output format.  Output a filled square following the format below.
This problem can only be submitted at Cogniterra.
