Lesson 3

Nikolai Chukhin · Alexander S. Kulikov

Exact Algorithms for the Chromatic Number. Let us now turn to the problem of finding the chromatic number of a graph.

Theorem. The chromatic number of any graph with \(n\) vertices can be computed in time \(O^{*}(3^{n})\).

Proof. Vertices of the same color in any proper coloring form an independent set. This allows us to write the following recurrence for the chromatic number. \[\chi(H)=\min\{\chi(H-I) + 1 \colon I \in \operatorname{IS}(H)\} \ ,\] where \(\operatorname{IS}(H) \subseteq 2^{V(H)}\) is the set of all independent sets of graph \(H\). It remains to use dynamic programming.

The running time of the resulting algorithm is \(O^{*}(3^{n})\). Indeed, for each subgraph \(H\) on \(k\) vertices we need to iterate over all its subsets of vertices: \[\sum_{k=0}^{n}\binom{n}{k}2^{k}=3^{n} \ .\]◼

Theorem (Björklund, Husfeldt, and Koivisto, 2006). The chromatic number of a graph can be found in time and space \(O^{*}(2^{n})\).

Proof. A graph can be colored with \(k\) colors if and only if its vertex set can be covered by \(k\) independent sets. Let \[U=\{(I_{1}, \dotsc, I_{k}) \colon \text{\(I_{i}\) is an independent set in \(G\)}\} \ .\] Let \(V(G)=[n]\), and define \[A_{j} = \left\{(I_{1}, \dotsc, I_{k}) \in U \colon j \in \bigcup_{i \in [k]}I_{i}\right\} \ .\] Then \(|\cap_{j \in [n]}A_{j}|\) is exactly the number of colorings. We compute this number using the inclusion-exclusion formula: \[\left| \bigcap_{i \in [n]}A_{i}\right| = \sum\limits_{I \subseteq [n]}(-1)^{|I|}\cdot \left| \bigcap\limits_{i \in I}(U \setminus A_{i})\right| \ .\]

It is easy to see that \(|\cap_{j \in I}(U \setminus A_{j})|\) is the number of \(k\)-tuples of independent sets not covering vertices from \(I\). This number is equal to \(\operatorname{IS}(V \setminus I)^{k}\), where \(\operatorname{IS}(J)\) is the number of independent sets in the subgraph induced by set \(J\). The function \(\operatorname{IS}\) for all sets \(J \subseteq V\) can be computed simultaneously using dynamic programming in time \(O^{*}(2^{n})\), based on the following recurrence: \[\operatorname{IS}(J)=\operatorname{IS}(J \setminus \{v\})+\operatorname{IS}(J \setminus N[v]) \ ,\] where \(v \in J\) (the first term accounts for independent sets not containing \(v\), the second for those that do).◼
