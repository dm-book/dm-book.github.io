Colorings · Application: Algorithms for Coloring

Lesson 1

Nikolai Chukhin · Alexander S. Kulikov

Exact algorithms for the 3-coloring problem. As we already know, checking whether a graph can be 2-colored is easy. But checking whether it can be 3-colored is algorithmically hard. One can simply try all possible 3-colorings, but there are \(3^{n}\) of them.

It's not hard to improve this naive bound to \(2^{n}\). Let us assume the graph is connected: if there are multiple connected components, they can be colored independently, and the problem becomes only easier. Then we color an arbitrary vertex in any color, and at each next step consider one of the two colors available for a vertex that already has a colored neighbor.

One can even obtain an upper bound of \(\binom{n}{n/3}\approx 2^{h(1/3)n}<1.89^{n}\). The idea is that in any 3-coloring, at least one color class has size at most \(n/3\). We try all \[\sum_{i=0}^{n/3}\binom{n}{i}\le n \binom{n}{n/3}\] possibilities for these vertices, and then try to 2-color the remaining graph.

Finally, this bound can be improved to \(1.5^{n}\).

Theorem. Checking whether a graph on \(n\) vertices can be colored in three colors can be done in (probabilistic) time \(O^{*}(1.5^{n})\).

Proof. The 3-coloring problem for \(G(V, E)\) can be easily reduced to 3-SAT. For each vertex \(v \in V\) and each color \(c \in [3]\), introduce a Boolean variable \[x_{v,c}=[\text{vertex \(v\) is colored in color \(c\)}]\ .\] Then, add the following clauses:

  • Each vertex \(v \in V\) is colored in at least one of the three colors: \[(x_{v,1}\lor x_{v,2}\lor x_{v,3}).\]
  • For each color \(c \in [3]\) and each edge \(\{u,v\} \in E\), vertices \(u\) and \(v\) cannot both be colored in color \(c\): \[(\overline{x_{u,c}}\lor \overline{x_{v,c}}) \ .\]

Without the first type of clauses, the formula would be in 2-CNF, whose satisfiability can be tested quickly (in linear time in its size). We can transform each 3-clause of the first type into a 2-clause as follows: for each vertex, randomly choose one of the three colors and forbid that color for the vertex. The result is a proper 2-CNF formula, which we can quickly test for satisfiability.

What is the probability that our algorithm finds a 3-coloring? If there is no coloring, the algorithm obviously won't find one. More interesting is the case when a 3-coloring exists. A fixed 3-coloring survives with probability \(p=(2/3)^{n}\). So the algorithm's error probability is at most \(1-p=1-(2/3)^{n}\). We repeat the algorithm \(20/p=20 \cdot 1.5^{n}\) times. The final error probability then drops significantly: \[(1-p)^{\frac{20}{p}}\le \left(e^{-p}\right)^{\frac{20}{p}}=e^{-20}\approx 2 \cdot 10^{-9}\ .\]◼
