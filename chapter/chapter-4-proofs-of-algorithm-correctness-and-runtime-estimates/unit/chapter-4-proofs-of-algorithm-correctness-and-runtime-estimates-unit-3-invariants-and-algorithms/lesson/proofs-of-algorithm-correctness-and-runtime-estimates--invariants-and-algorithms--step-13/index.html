Try to sort it in eight moves on your own or using the Python code above. Note, however, that if neither we nor the code can sort it in eight moves, this still does not mean that it is impossible: perhaps there is some other clever strategy that can do it.

To prove that it is indeed impossible, we will use semi-invariants! Specifically, for the sequence of volumes we will define a certain non-negative numerical parameter. Next, we will prove the following three facts.

  1. For each move, this parameter decreases by no more than one.
  2. For an ordered (ascending) sequence, this parameter equals zero.
  3. There are sequences for which this parameter equals nine.

Try to come up with such a semi-invariant on your own before looking below: do not deny yourself the pleasure of inventing it!
