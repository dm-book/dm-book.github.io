The strategy we discussed above is quite simple to implement. The code below uses zero-based indexing for moves, volumes, and positions. 

def sort_books(books):
    day = 0

    for i in range(len(books)):
        j = books.index(i)
        if j != i:
            books[i], books[j] = books[j], books[i]
            print(f'After day {day}: {books}')
            day += 1
