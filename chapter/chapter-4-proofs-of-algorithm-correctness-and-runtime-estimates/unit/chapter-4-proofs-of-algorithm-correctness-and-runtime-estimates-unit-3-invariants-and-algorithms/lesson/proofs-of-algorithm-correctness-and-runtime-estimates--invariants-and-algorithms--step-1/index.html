Nikolai Chukhin · Alexander S. Kulikov

An invariant is a property that is preserved throughout some process. Invariants are often used in discrete mathematics and computer sciences—for example, to prove the correctness of algorithms and programs (often using loop invariants, i.e., statements that remain true on each iteration of a loop), as well as to estimate runtime.
