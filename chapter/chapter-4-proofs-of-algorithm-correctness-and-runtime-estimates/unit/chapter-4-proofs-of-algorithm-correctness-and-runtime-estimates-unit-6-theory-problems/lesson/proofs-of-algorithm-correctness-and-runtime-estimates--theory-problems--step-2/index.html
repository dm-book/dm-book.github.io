Lesson 2

Nikolai Chukhin · Alexander S. Kulikov

Advanced Problems.

  1. (20 points) Several boxes are arranged in a circle. Each box may contain one or more balls (or be empty). In one move, one is allowed to take all the balls from any box and distribute them clockwise, starting from the next box, placing one ball in each box.
    • (10 points) Prove that if on each move the balls are taken from the box where the last ball was placed in the previous move, the initial arrangement of balls will eventually repeat.
    • (10 points) Prove that any arrangement of balls can be transformed into any other arrangement in a finite number of moves.
    Hint:
    For part (a), consider the state of the system. What defines a “state”? Also, think about whether a state uniquely determines the previous state. For part (b), the goal is to show reachability. Can you demonstrate that one can reach a “canonical” state from any arrangement?
  2. (20 points) Given \(n\) stones with different weights. In one turn, you can compare two stones. How many comparisons are necessary and sufficient to find the heaviest and the second-heaviest stone?
  3. (25 points) Given two groups of pebbles, where the pebbles in each group are ordered by weight. The first group contains \(n\) pebbles, and the second group contains \(m\) pebbles, where \(2m<n\). It is required to sort all the pebbles by weight. Construct an algorithm that solves this problem in \(O(m \log \frac{n}{m})\) comparisons.
    Hint:
    By the statement, \(2m < n\), and thus it is reasonable to consider the classical algorithm with complexity \(m \log(n + m)\), where for each element from the group of size \(m\), a binary search is performed to locate its position. Let us examine the binary search procedure more closely: suppose we select some pebble from the \(m\) elements and determine its position. What additional information can be inferred from this search? Note that binary search itself cannot be improved; however, the key aspect of this problem lies in the necessity of performing a large number of binary searches.
  4. (25 points) Given \(\frac{3^k - 1}{2}\) stones, all of them have equal weight except one fake stone. It is unknown whether the fake stone is heavier or lighter than the others. Find the fake stone in \(k\) weighings on scales.
  5. (50 points) Given \(n\) stones called \(a[0], a[1], …, a[n - 1]\) with different weights. In one turn, you can compare two stones. Prove that \(O(n \log n)\) non-adaptive weightings are enough to order all the stones. In other words, you have some function \(\operatorname{cmp}(i, j)\) that puts \(a[i] \gets \min\{a[i], a[j]\}\) and \(a[j] \gets \max\{a[i], a[j]\}\) (simultaneously). You should write a program that uses such functions and does not depend on the input. For example, for \(n = 3\) the program is: \(\operatorname{cmp}(0, 1), \operatorname{cmp}(1, 2), \operatorname{cmp}(0, 1)\). (The writer does not know a simple solution to this problem.)
    Hint:
    Prove the following lemma, and then construct the algorithm based on it.Lemma. If a sorting network correctly sorts all \(2^{n}\) sequences consisting of zeroes and ones, then it is also valid for arbitrary ordered inputs. Therefore, it suffices to consider only the \(0/1\) case.
