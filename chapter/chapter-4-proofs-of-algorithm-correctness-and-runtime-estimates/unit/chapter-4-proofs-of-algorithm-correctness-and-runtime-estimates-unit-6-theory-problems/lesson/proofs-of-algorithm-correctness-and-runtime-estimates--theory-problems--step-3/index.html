Lesson 3

Nikolai Chukhin · Alexander S. Kulikov

Optional Problems.

  1. (20 points) Prove that, if the occurrence frequency of each symbol is less than \(\frac{1}{3}\), then each symbol in the Huffman code has length at least \(2\).
    Hint:
    Recall, that for a symbol to have a codeword length of \(1\), it must be directly attached to the root. This means its frequency must be one of the two largest frequencies at the very last step.
  2. (20 points) Prove that the probability of compressing a random binary file by at least one byte using any archiver does not exceed \(\frac{1}{128}\).
  3. (20 points) We know already that the Huffman code can be constructed in time \(O(n\log n)\). Show that if the input frequencies are sorted (\(p_{1} \le \dotsb \le p_{n}\)), then one can construct the Huffman code in time \(O(n)\).
    Hint:
    The standard algorithm uses a min-priority queue which takes \(O(\log n)\) for extraction and insertion operations. The key to achieving \(O(n)\) time when frequencies are already sorted is to avoid the general priority queue operations.
  4. (20 points) Prove the following formula: \[\begin{align*}H(p_{1}, \dotsc, p_{n}, q_{1}, …, q_{m})&= H(p_{1} + \dotsb + p_{n},\ q_{1} + \dotsb + q_{m}) \\&\quad + (p_{1} + \dotsb + p_{n})\ H(p_{1}', \dotsc, p_{n}') \\&\quad + (q_{1} + \dotsb + q_{m})\ H(q_{1}', \dotsc, q_{m}'),\end{align*}\] where \(p_{1} + \dotsb + p_{n} + q_{1} + \dotsb + q_{m} = 1\), and \[p_{i}' = \frac{p_i}{p_1 + \dotsb + p_n}, \qquad q_{i}' = \frac{q_i}{q_1 + \dotsb + q_m}.\]
  5. (25 points) The Kraft–McMillan inequality states that if positive integers \(l_{1}, \dotsc, l_{n}\) are such that \(2^{-l_1}+ \dotsb + 2^{-l_n}\le 1\), then there is a prefix code \(c_{1}, \dotsc, c_{n}\) with code lengths \(l_{1}, …, l_{n}\). Construct an online algorithm for this problem: on the \(i\)-th iteration, the algorithm receives \(l_{i}\) and should output \(c_{i}\) of length \(l_{i}\), such that \(c_{1}, …, c_{i}\) are a prefix code.
    Hint:
    Note that, in this case, assigning each \(c_{i}\) to an arbitrary codeword of length \(l_{i}\) will not suffice. Indeed, consider the lengths \(l_{1} = 2\), \(l_{2} = 2\), and \(l_{3} = 1\). Suppose that \(c_{1} = 01\) and \(c_{2} = 10\); then there is no available position for \(c_{3}\). A correct encoding in this instance would be \(c_{1} = 01\), \(c_{2} = 00\), and \(c_{3} = 1\).
